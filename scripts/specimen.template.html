__FAMILY__ キウイと楓

英字は Maple Mono、和文は Kiwi Maru。半角600・全角1200の等幅で、8ウェイトとイタリックがあります。細い字と広い字の間合いを整える Texture Healing、大きめの濁点、Kiwi Maru の旧字形切り替えも備えています。下の操作パネルでウェイトや字形切り替え(OpenType の cv / ss)を変えると、すべての見本に反映されます。見本の文章はクリックして書き換えられます。

Maple Mono の字形切り替え(cv / ss)

コード

// キウイと楓のフォントで、のんびりコーディング
type Fruit = { name: string; 甘さ: number };

const basket: Fruit[] = [
  { name: "キウイ", 甘さ: 7 },
  { name: "メープル", 甘さ: 10 },
];

for (const f of basket) {
  if (f.甘さ >= 8 && f.name !== "") {
    console.log(`${f.name} は甘い！ → 0O 1lI |`); // [TODO] 計量する
  }
}

等幅のまま、細い字(i l j r t f I 1)の隣にある広い字(m w M W)は細い字の側へ少し広がり、細い字は離れます。広い字と細い字に挟まれたその他の字も、細い字の側へ寄ります(Smart Kerning)。字の送り幅は変えないので、桁は崩れません。

和文のつなぎ

ラーメン → ラーーーメン   すごーーーい！
ああ〜 → ああ〜〜〜ん     るんるん〜〜♪
それは――つまり

Maple の無限矢印と同じ発想で、和文の記号も続けて打つとつながります。長音「ー」と波ダッシュ「〜」は2つ以上続くと1本の線と波に、2倍ダッシュ「――」は隙間なくつながります。1つだけのときは普段の字形のままです。

既定で、長音「ー」を短く、カタカナ「ヘベペ」を細く高く、全角英数記号を Maple の字形にしています。cv92 を有効にすると、漢字と紛らわしいカタカナがさらに小さくなります。

キウイと楓の、やわらかい文章用フォント

吾輩は猫である。名前はまだ無い。どこで生れたかとんと見当がつかぬ。何でも薄暗いじめじめした所でニャーニャー泣いていた事だけは記憶している。「キウイ」と『メープル』（楓）。 The quick brown fox jumps over the lazy dog. AVATAR, To, Type, LT。Mapleで書いたcodeをGitHubに置く、トイレのくつした。

英字は Maple の字形のまま、輪郭から字間を自動で決め直しています。数字は桁が揃う同じ幅、かなと約物は詰め組み、漢字は全角(1100)の中央です。等幅を前提にしたリガチャは外しています。AV や To、ディ のように片側が開いた字の組はカーニングで詰め、和文と英字が接するところには少しだけ間(和欧間のアキ)を入れています。

英字: Maple Mono v7.9 (SIL OFL 1.1) / 和文: Kiwi Maru (SIL OFL 1.1)。合成フォント __FAMILY__ / __PROP_FAMILY__ も SIL OFL 1.1 で配布予定。 JPDOC 版(矢印・図形を全角にした文書向け)と Nerd Fonts 版もあります。容量を抑えるため、このページには見本に出てくる文字とかな・英数だけを埋め込んでいます。書き換えた文字が埋め込みに無い場合は代替フォントで表示されます。
